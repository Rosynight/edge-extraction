# edge-extraction
利用Opencv提取图像边缘

系统使用说明
双击运行 1.py，弹出“选择输入源”小窗：
点“打开本地图片”——在弹出的文件框里选中一张 jpg/png/bmp/tiff 照片，支持中文路径。
点“打开摄像头拍照”——程序自动找第一个可用摄像头，窗口出现实时画面；按 q 拍照，按 ESC 直接退出。拍照后自动把快照存为 snap_时间戳.png，并立即进入抠图流程。
进入主窗口“image”：
第①步：画矩形。按住左键拖出绿色方框，把要保留的主体框住；框完按 Enter，程序自动初分割，弹出结果窗口“result”。
第②步：精修边缘。此时主窗口提示“左键=前景白线，右键=背景黑线”。用左键在缺失部分刷白线，用右键在多出来的背景刷黑线；每刷完按 N，程序立即重算并更新结果窗口。可反复刷、反复按 N，直到满意。
保存与退出：
按 Ctrl+S 弹出保存框，输入文件名，得到一张带透明通道的 PNG，边缘已自动抗锯齿。
按 R 可重画矩形，按 Q 可清空手绘线，按 ESC 退出全部窗口。程序会在退出时自动释放摄像头，不占用设备。
